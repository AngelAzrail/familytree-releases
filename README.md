# FamilyTree downloads

Публичные сборки **FamilyTree**: Android APK и Windows zip.

В этом репозитории **только файлы релизов**. Исходный код остаётся в приватном репозитории.

## Установка

Скачайте нужный файл со страницы [Releases](https://github.com/AngelAzrail/familytree-releases/releases/latest):

- **Android** — `FamilyTree-<версия>.apk`
- **Windows** — `FamilyTree-<версия>-windows.zip`, распакуйте и запустите `familia.exe`

В приложении то же самое: Настройки → Проверить обновления.

This repository is **downloads only**. Source stays private.
