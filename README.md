# «Корни» — генеалогическое древо. FamilyTree

**Офлайн-приложение «связь поколений»** для Android и Windows.

«Корни» помогают вести семейную историю: хранить карточки людей, строить
генеалогическое древо, следить за датами и обмениваться деревом между
устройствами — **без интернета и без серверов**. Все данные живут только
на вашем устройстве.

## Возможности

- **Карточки людей** — ФИО, пол, даты, дополнительные даты (венчание, крестины…),
  биография с голосовым вводом, родственники и связи (родитель, ребёнок, супруг,
  сиблинг, своя).
- **Генеалогическое древо** — автоматическое построение по поколениям, масштаб и
  сдвиг жестами, поиск по дереву с подсветкой, выбор корня.
- **Календарь событий** — дни рождения и даты смерти повторяются каждый год,
  бейджи с числом событий, просмотр месяца или всего года.
- **Быстрый поиск** — по имени и биографии, нечёткий (понимает похожие фамилии),
  фильтры по полу и годам рождения.
- **Импорт и экспорт** — свой формат `.ftree`: весь архив, ветка или выбранные;
  файлом, QR-кодом или строкой из буфера обмена. Мастер слияния с умными
  совпадениями и разрешением конфликтов полей.
- **Синхронизация по Wi-Fi** — обмен деревом между устройствами в одной сети;
  на Android — напрямую по **Wi-Fi Direct**.
- **Корреляции** — поиск возможных дубликатов и упоминаний в биографиях
  в фоне, с причинами совпадений.
- **Три темы** — светлая, тёмная и сепия.
- **Встроенная проверка обновлений** — приложение само подскажет новую версию.

## Платформы

| Платформа | Минимальная версия | Формат |
|---|---|---|
| Android | 8 (API 26) | APK |
| Windows | 10 | Zip + `familia.exe` |

## Установка

Скачайте нужный файл со страницы [Releases](https://github.com/AngelAzrail/familytree-releases/releases/latest):

- **Android** — `FamilyTree-<версия>.apk`. Разрешите установку из неизвестных источников.
- **Windows** — `FamilyTree-<версия>-windows.zip`. Распакуйте и запустите `familia.exe`.

В самом приложении: **Настройки → Общие → Проверить обновления**.

# Пользовательская инструкция

## Разделы приложения

Четыре раздела (внизу на телефоне, слева на компьютере):

- **Древо** — генеалогическое древо вокруг выбранного человека.
- **Список** — все карточки людей, поиск и фильтры.
- **Календарь** — события по датам.
- **Настройки** — тема, импорт/экспорт, синхронизация, корреляции, обновления.

## Список людей

- **Добавить человека** — кнопка `+`. Обязательно имя или фамилия.
- **Поиск** — по имени, фамилии и биографии; нечёткий поиск понимает похожие
  фамилии («Иванофф» найдёт Иванова).
- **Фильтры** — кнопка-«воронка»: пол и годы рождения.
- **Сортировка** — по фамилии или по дате рождения.
- Список подгружается по 50 человек по мере прокрутки.

## Карточка человека

Вкладки:

- **Основное** — ФИО, пол, даты рождения/смерти, дополнительные даты.
- **Родственники** — связи: родитель, ребёнок, супруг, сиблинг, пользовательская.
- **Биография** — свободный текст, на поддерживаемых устройствах — голосовой ввод.

## Древо

- Строится автоматически вокруг **корня** (выбирается в шапке).
- Масштаб — жестами (телефон) или колесом мыши (компьютер); сдвиг — перетаскиванием.
- Нажатие на карточку — профиль человека. Поиск по дереву подсвечивает карточки.
- «Показать в древе» из карточки делает человека корнем.

## Календарь

- На телефоне — месяц, на широком экране — весь год.
- Даты с событиями помечены **бейджем с числом событий**; даты повторяются каждый год.
- Нажатие на дату — список лиц и событий.

## Импорт и экспорт

Формат `.ftree` (сжатый JSON). GEDCOM/CSV не поддерживаются.

- Экспорт: **всё дерево**, **ветка** (от человека на N поколений) или **выбранные**.
- Поделиться небольшой веткой можно **QR-кодом** или строкой из буфера.
- Импорт: файл `.ftree`, **сканирование QR** (Android) или **вставка из буфера**.
- После импорта — **мастер слияния**: для каждого совпадения «Слить»,
  «Дубликат» или «Пропустить».

## Синхронизация

- **Рядом по Wi-Fi**: одно устройство «Принимает рядом», второе «Отправляет рядом»
  (QR или строка сопряжения). Нужна одна сеть Wi-Fi.
- **Wi-Fi Direct (Android)**: обмен напрямую, общая сеть не нужна.

## Корреляции

Настройки → Корреляции. Приложение находит возможные дубликаты и упоминания
в биографиях. Для находки: **создать связь**, **игнорировать** или
**ложное срабатывание**.

## Настройки

- **Общие** — количество людей, путь к базе, версия, проверка обновлений,
  тема (светлая/тёмная/сепия), «Я в дереве».
- **Синхронизация**, **Импорт**, **Экспорт** — отдельные разделы.
- **«Я в дереве»** — укажите свою карточку, чтобы приложение знало, кто вы.

## Данные и приватность

- Всё хранится локально (SQLite) на устройстве.
- Интернет используется только для проверки обновлений — по вашей команде.
- Передача дерева между устройствами идёт напрямую по локальной сети.
